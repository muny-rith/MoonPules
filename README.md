# MoonPulse - Social Media Analytics & Post Tracker

A modern PERN stack (PostgreSQL, Express, React, Node) social media dashboard and content scheduling platform.

## Features
- **Social Analytics Dashboard**: Real-time stats, view tracking, and performance metrics across platforms (TikTok, Facebook, Telegram, Instagram).
- **Interactive Column Chart**: Net growth insights, peak performance highlights, and rich hover tooltips.
- **Task & Schedule Tracker**: Track and schedule upcoming social media posts.

## Project Structure
- `/frontend`: React + Vite client interface
- `/server`: Node.js + Express backend API
- `/zRequirments`: Documentation and templates

## Getting Started

### 1. Backend Setup
```bash
cd server
npm install
npm run start
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
